    Aviso de privacidad

    Para generar documentos, esta aplicación procesa el contenido de los archivos que subas (CV, proyectos, certificaciones) y de las ofertas que pegues. Esa información puede incluir datos personales y sensibles.

    • Envío a Google Gemini: fragmentos de tus documentos y la oferta se envían a la API de Google para crear embeddings y generar el texto. En el nivel gratuito, Google puede usar estos datos para mejorar sus productos y personal autorizado podría revisarlos.
    • Almacenamiento: tus documentos se guardan como fragmentos en la base vectorial del servidor donde se ejecuta la app. Puedes borrarlos en cualquier momento desde la lista de fuentes.
    • Recomendación: no subas documentos con datos que no quieras compartir (número de identificación, domicilio, datos de salud, etc.).
    • Los resultados son generados por IA: revísalos antes de usarlos.

    No puedes usar la aplicación sin aceptar el aviso de privacidad

    Tus datos no se han enviado ni almacenado.
